# TUG//LAB — Development Brief

This file holds the authoritative development brief for TUG//LAB (Timed Up and Go,
standalone portrait-mobile on-device computer-vision web app).

> The full brief text lives in the project's issue/owner notes. This copy records
> the two defining decisions for this build:
>
> 1. **No-install workflow.** Vanilla HTML/CSS/JS only — no Node, npm, bundler,
>    Git, or Python required at any step. MediaPipe loads from a pinned CDN; tests
>    run in a browser page; the data dictionary is generated by a browser page;
>    deployment is via the GitHub web UI; Google Sheets capture uses Apps Script.
>
> 2. **Operator-following (panning) portrait camera** — the requested change from
>    the original static landscape setup. The operator holds the phone in portrait
>    and follows the participant (stand → walk to cone → turn → walk back → sit).
>    Because a moving camera breaks the "image x-axis = walking axis" assumption,
>    analysis is driven primarily by MediaPipe **world landmarks** (metric,
>    pelvis-origin, camera-motion-invariant for body-relative geometry), and the
>    travelled path is reconstructed by integrating per-step foot displacement in
>    the world frame. See `.kiro/steering/tech.md` and `js/analysis.js`.

See `README.md` for the full manual and `DATA_DICTIONARY.md` for every field.
